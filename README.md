# Feishu Fields - 飞书多维表格捷径插件

## 插件简介

Feishu Fields 是一系列为飞书多维表格设计的捷径插件，专注于视频处理功能，帮助用户快速完成常见的视频编辑任务。

## 功能列表

### 🎬 视频编辑工具

| 插件名称 | 功能描述 | 图标 |
|---------|----------|------|
| wefly-video-add-text | 视频叠加文本 | 📝 |
| wefly-video-add-video | 视频叠加视频 | 🎞️ |
| wefly-video-crop | 视频裁剪 | ✂️ |
| wefly-video-merge | 多视频合并 | 🔗 |

## 功能详情

### 📝 wefly-video-add-text
- **功能**: 在视频上添加自定义文字
- **应用场景**: 添加标题、字幕、水印、时间戳等

### 🎞️ wefly-video-add-video
- **功能**: 将一个视频叠加到另一个视频上
- **应用场景**: 画中画效果、LOGO添加、多视角展示

### ✂️ wefly-video-crop
- **功能**: 裁剪视频尺寸和时长
- **应用场景**: 调整画面比例、截取精彩片段、移除不需要的部分

### 🔗 wefly-video-merge
- **功能**: 将多个视频合并为一个
- **应用场景**: 制作合集、拼接片段、创建连续内容

## 使用说明

1. 在飞书多维表格中安装相应的插件
2. 选择包含视频链接的单元格
3. 运行插件并按照提示操作
4. 处理完成后，结果将自动保存到指定位置
